# matisse-walk.github.io

**Matisse's Montparnasse**: a mobile-first walking guide to the Paris of Henri Matisse and his
friends, for the MATISSE project meeting in Paris, 21 October 2026. Live at
<https://matisse-walk.github.io/>.

A simple static site: HTML pages, one stylesheet, public-domain images and MP3 audio episodes.
No build step, no framework. GitHub Pages serves the `main` branch root.

| Path | What |
|---|---|
| `index.html` | cover and "Matisse in 60 seconds" |
| `map.html` | the route (short and long), stop list, Google Maps link |
| `stop-1.html` … `stop-5.html` | the five stops: picture, audio, story |
| `steins.html`, `luxembourg.html` | bonus pages |
| `print.html` | all pages in order, A5 print stylesheet (the PDF gift) |
| `art/` · `audio/` · `info/` · `map/` | images with credits · episodes · infographics · map renders |
| `fr/` · `ru/` | release 2: French; Russian for kids |

Audio and infographics are generated with NotebookLM from fact-checked notes; the notes are the
reference, not the recordings. Artworks are in the public domain (EU, life + 70 years); every
image carries its credit. Text © Andrey Sadovykh, CC BY 4.0. Code MIT.
